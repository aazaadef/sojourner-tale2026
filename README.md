# Sojourner under Sabotage — Replication Package

**Paper:** *Teaching Software Testing and Debugging Through a Serious Game: An Empirical Classroom Study with Sojourner under Sabotage*

Accepted as a short paper at **IEEE TALE 2026**, Pattaya, Thailand.

## Contents

| File | Description |
|---|---|
| `main.tex` | LaTeX source of the paper |
| `analysis.py` | Replication script: every statistic and figure in the paper |
| `data_pre_questionnaire.csv` | Pre-session MCQ and self-confidence responses (N=22) |
| `data_post_questionnaire.csv` | Post-session questionnaire responses (N=21) |
| `telemetry.json` | Pseudonymized in-game telemetry (3,176 events from 23 accounts; 3,161 from the 22 matched students analysed in the paper) |
| `figures/` | Figures regenerated by `analysis.py` |
| `instruments/` | The pre- and post-session questionnaires as administered (blank Google Forms, PDF) |

## Reproducing the results

```bash
pip install scipy numpy matplotlib
python analysis.py
```

The script reads only the files in this directory and prints every number
reported in the paper, then regenerates the figures.

## Privacy

The telemetry export produced by the game embeds account records. Before
release, every account reference was rewritten to the participant's
self-generated questionnaire code, account objects were reduced to that code
alone — removing names and password hashes — and instructor, admin and test
accounts were removed entirely. One account that played but never completed a
questionnaire appears as `ANON01`. The questionnaire CSVs contain no names,
student numbers, e-mail addresses or IP addresses. Free-text answers are
released verbatim; three were written in Portuguese.

## Study design

A single ~2-hour session combining a 50-minute lecture with ~60 minutes of
guided gameplay, with 22 master's students. Because both components were
delivered together and there was no control group, the results are exploratory
and describe associations rather than establishing that the game caused the
observed changes.
